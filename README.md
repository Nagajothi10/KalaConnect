# KalaConnect – AI-Powered Handmade Marketplace

KalaConnect is an AI-powered marketplace designed to connect Indian artisans with customers. It helps artisans showcase their handmade products and reach a wider audience.

## Features
- Artisan and customer registration and login
- Browse handmade products and view product details
- Shopping cart and order management
- Artisan dashboard for managing products and orders
- AI-powered craft assistant using the Gemini API
- AI-generated product titles, descriptions, and tags

## Technologies Used
- **Frontend:** React, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** SQLite
- **Authentication:** JWT
- **AI Integration:** Google Gemini API
- **Additional Technology:** OpenCV

## Getting Started
1. Clone this repository.
2. Install the frontend and backend dependencies using `npm install` in their respective folders.
3. Configure the required environment variables in the backend `.env` file.
4. Start the backend and frontend using the project's configured commands.

Refer to the `client` and `server` folders for the application code.

## Security
Never commit API keys, passwords, or `.env` files. Configure your own API keys locally before running the application.
